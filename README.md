# Personal Context Garden Starter

Templates for organizing useful context for AI assistants while keeping personal and sensitive information under your control.

This repository contains blank templates and a fictional example only. It is not a copy of a personal knowledge base. Keep real personal context in a private, access-controlled location and share only the minimum needed for a task.

## Quick start

1. Copy `templates/agent-context.md` into a private workspace.
2. Fill in only details that are useful to your assistants.
3. Use `templates/project-brief.md` for project-specific context.
4. Review the sharing checklist before giving files to an assistant or publishing them.
5. Update or remove details when they are no longer accurate.

## Files

- `templates/agent-context.md` — stable preferences, working practices, and boundaries.
- `templates/project-brief.md` — goals, current state, decisions, and next actions for one project.
- `examples/demo-context.md` — a fictional example showing how concise context can be structured.

## Sharing checklist

- Remove passwords, API keys, recovery codes, and private URLs.
- Check for personal contact details, precise location, private health or financial information, and other details that do not need to be shared.
- Separate stable preferences from temporary project notes.
- Mark uncertainty and include a review date for details that can go stale.
- Treat every published file as public and searchable.
